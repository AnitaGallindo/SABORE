# Saborê

Projeto acadêmico de uma plataforma para divulgação e reserva de oficinas gastronômicas.

## Tecnologias
- React + Vite
- Node.js + Express
- MongoDB (integração será feita na próxima etapa)

## Como iniciar

### Front-end
```bash
cd frontend
npm install
npm run dev
```

### Back-end
Em outro terminal:
```bash
cd backend
npm install
npm run dev
```

O front-end é uma base navegável com dados demonstrativos. Cadastro, login e reservas ainda não estão conectados à API nem ao MongoDB.

## Escopo desta versão
- Oficinas previamente cadastradas.
- Consulta de oficinas.
- Formulário inicial de agendamento.
- Login/cadastro visual.
- Confirmação de pagamento apenas simulada.
- Sem cobrança real e sem painel administrativo.
